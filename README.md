# Number Guessing Game

A beginner Python project where players try to guess a randomly generated number within a limited number of attempts.

## Features

- Three difficulty levels: Easy, Medium and Hard
- Different number ranges and attempt limits for each difficulty
- Input validation and error handling
- Feedback indicating whether a guess is too high or too low
- Replay functionality

## Technologies

- Python
- `random` module

## How to Run

1. Ensure Python is installed.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python main.py
```
